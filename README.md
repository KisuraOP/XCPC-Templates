2023 年至今 UESTC_EndlessEmbrace（UESTC_无尽相拥）所使用的 XCPC 模板库。

本项目使用 llleixx 编写的[工具](https://github.com/llleixx/XCPC-Templates)进行组织，可以在 [Releases](https://github.com/KisuraOP/XCPC-Templates/releases) 中下载最新的 pdf。彩色版为 output_{tag}.pdf，黑白打印版为 output_{tag}_bw.pdf，后者对比度经过特殊调整，实测打印出来更清晰。

---

仅纪念可能是我人生中最美好的一段时光。

须知：本模板在如下环境中编写。如果你想使用本模板，后三行对你尤其重要。

```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define double long double
#define inf 0x3fffffffffffffff
```
